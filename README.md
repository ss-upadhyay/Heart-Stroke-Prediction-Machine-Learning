# Heart Stroke Prediction - Machine Learning

A machine learning project to analyse patient health data and predict the likelihood of stroke using classification algorithms.

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Project Overview

This project includes data exploration, preprocessing, handling missing values, categorical data processing, and classification model development.

Multiple machine learning models are explored, including:

- Logistic Regression
- Decision Tree
- Random Forest
- Support Vector Classifier (SVC)

Model performance is evaluated using classification metrics and confusion matrices.

## Dataset

The dataset contains 5,110 patient records with demographic and health-related attributes such as age, gender, hypertension, heart disease, average glucose level, BMI, smoking status, and stroke outcome.

The dataset is not uploaded separately to this repository.
